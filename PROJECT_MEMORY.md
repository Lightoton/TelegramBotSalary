# Память Проекта: TelegramBotSalary (Auto-Memory)

## 1. Суть проекта и текущий прогресс
**Суть:** Разработка Telegram-бота для учета доходов и расходов фрилансеров/самозанятых.
**Прогресс:** Проект был серьезно отрефакторен (Release v2.0 - ветка `refactor/architecture-v2`).
- Решены проблемы OOM и N+1 путем написания SQL-запросов (например, `findAllByChatIdAndTransactionDateBetween`).
- Бот переведен на Stateless-архитектуру: `BotSession` сохраняется в БД PostgreSQL, а не в оперативной памяти.
- Гигантский God Object `UpdateHandler` разбит на мелкие обработчики (паттерн Command/State: `MainMenuHandler`, `OnboardingHandler` и др.), реализующие интерфейс `BotStateHandler`.
- Заложена база для интернационализации (`messages_ru.properties`).

## 2. Стек технологий и архитектура
*   **Язык:** Java 21
*   **Фреймворк:** Spring Boot 3
*   **База Данных:** PostgreSQL
*   **Архитектурные решения v2.0:**
    *   `UpdateHandler` — теперь только диспетчер, делегирующий логику `List<BotStateHandler>`.
    *   Хендлеры изолированы по доменам (`BudgetHandler`, `IncomeHandler`, `SettingsHandler`).
    *   Сессии хранятся в PostgreSQL таблице `bot_session` (`BotSessionRepository`).

## 3. Важные технические нюансы и костыли
*   **Окружение пользователя:** Windows. Запуск через Docker Desktop.
*   **Безопасность БД:** Порт `5432` спрятан внутри Docker.
*   **Парсинг чисел:** Замена запятой на точку `text.replace(",", ".")`.
